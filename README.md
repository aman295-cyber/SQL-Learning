# SQL Learning Journey 🐘

Welcome to my **SQL-Learning** repository! 🚀

This repository documents my journey of learning **SQL using PostgreSQL and pgAdmin**, with a strong focus on hands-on practice, database design, data manipulation, and technical interview preparation.

My goal is to build a strong foundation in SQL and develop practical database skills relevant to **Data Analytics, Machine Learning, and AI/ML Engineer placement opportunities**.

## 📚 Topics Covered

### SQL Fundamentals
- SQL Introduction and Basic Queries
- Database and Table Creation
- CRUD Operations: `CREATE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`
- SQL Data Types
- SQL Constraints: `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`, `CHECK`, `DEFAULT`

### Querying and Data Manipulation
- SQL Clauses: `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `LIMIT`, `OFFSET`, `DISTINCT`
- SQL Operators and Filtering
- Aggregate Functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- String Functions: `UPPER()`, `LOWER()`, `LENGTH()`, `TRIM()`, `CONCAT()`, `SUBSTRING()` and more
- Conditional Logic using `CASE`
- Modifying Tables using `ALTER TABLE`

### Database Relationships
- Primary Keys and Foreign Keys
- One-to-One Relationships
- One-to-Many Relationships
- Many-to-Many Relationships
- Relationship Implementation using Foreign Keys and Junction Tables
- SQL JOINs and Combining Data from Multiple Tables

## 🛠️ Projects and Practical Exercises

### 1. Flipkart Database Schema
Designed a product database schema to practice database creation, product information management, and SQL queries.

**Concepts practiced:**
- Table creation and data insertion
- Product pricing and stock management
- SQL constraints and data integrity
- Filtering, sorting, and aggregate queries
- `CASE` expressions for price categories and stock status
- Practical data manipulation using SQL

### 2. Student Table Constraints Practice
Practiced applying SQL constraints and modifying table structures to understand how databases maintain data integrity.

**Concepts practiced:**
- Primary and unique keys
- `NOT NULL`, `CHECK`, and `DEFAULT` constraints
- Adding, modifying, renaming, and dropping columns
- Changing column data types
- Using `ALTER TABLE` to modify existing tables

### 3. SQL Relationships Practice
Practicing database relationships using separate tables and realistic sample data.

**Concepts practiced:**
- One-to-One relationships
- One-to-Many relationships using Students and Marks tables
- Many-to-Many relationships using junction tables
- Primary key and foreign key implementation
- Understanding how related records are connected

### 4. SQL JOIN Practice
Learning to retrieve meaningful information from related tables by combining records.

**Concepts practiced:**
- Joining tables using matching keys
- Understanding table aliases
- Retrieving student details with subject-wise marks
- Practicing relationship-based queries

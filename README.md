# SQL Learning Journey 🐘

## 📚 Topics Covered

- SQL Fundamentals
- Database and Table Creation
- CRUD Operations (`CREATE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`)
- SQL Data Types
- SQL Constraints (`PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`, `CHECK`, `DEFAULT`)
- SQL Clauses (`WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `LIMIT`, `OFFSET`, etc.)
- SQL Operators
- Aggregate Functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- String Functions (`UPPER`, `LOWER`, `TRIM`, `CONCAT`, `SUBSTRING`, and more)
- Practical SQL Query Exercises
